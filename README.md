## The idea

Nexora is a personal AI system built around one simple idea:

> **You shouldn't have to remember where you put something.**

Send it a message. Upload a document. Save a screenshot. Record a voice note. Add a task.

Nexora turns those pieces of information into a connected personal memory that you can search and act on later.

## Memory

The memory layer is the core of Nexora.

<div align="center">

<img src="https://github.com/user-attachments/assets/1ddd4025-1f66-48ab-b953-ab3d80159617" alt="Nexora memory system" width="700">

</div>

Information can enter through text, voice, images, documents, email or connected services.

Nexora extracts useful information, connects related memories and makes them available through semantic and contextual search.

---

## Local-first

<div align="center">

<img src="https://github.com/user-attachments/assets/2cdc4729-86ce-41ac-8ddf-588fb4b26920" alt="Nexora local-first architecture" width="900">

</div>

The project is being designed around local processing wherever practical.

The goal is to make Nexora usable without depending on expensive AI APIs, while still allowing optional cloud services when they provide a useful capability.
